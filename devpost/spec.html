Go Frog Go
technical spec

Next.js on Vercel (Strawberry Digital). Jev picks every move. Nemotron on Nebius teaches after every run.

IN PLAIN LANGUAGE

The page draws the road and runs the clock in beats: the frog moves, then the cars move. It waits for each move, so a slow answer only pauses the game.

Jev gets the situation in plain sentences ("In lane +1, a car reaches column 4 this beat") and the playbook, and picks one of five moves with a confidence. It's reached through Vercel AI Gateway, with no waitlist.

Nemotron on Nebius Token Factory reads the last few beats after a run ends and writes what happened plus one rule. The rule joins the playbook, and the next run replays the same road.

ONE BEAT, ONE DEATH

WHAT JEV SEES

Facts are phrased as time, so "this beat" means moving there now gets you hit. Move descriptions carry facts, never verdicts.

POST https://ai-gateway.vercel.sh/typesafe/v1/systemone
{ "model": "typesafe-ai/jev",
  "state": "You are on grass, row 0, column 4.
            Lane +1 (road, cars move left 2 per beat): a car reaches column 4 this beat.
            Lane +2 (road): a car reaches column 4 in 3 beats.
            Behind you: the edge; you can't go back.",
  "questions": { "move": { "type": "choice",
    "instructions": "Pick the frog's next move... Playbook:\n1. Jump forward.",
    "criteria": {
      "forward": "Step into lane +1, column 4. A car there reaches column 4 this beat.",
      "wait":    "Stay on grass, column 4. No cars on grass.",
      "left":    "Stay on grass, move to column 3.", "right": "...", "back": "..." } } } }

Returns answers.move.choice, .probabilities for all five, .confidence. About $0.013 per 1,000 beats.

THE PIECES

Game world · lib/game/world.ts → prd: Endless road
  • 9 columns. Each row generated from rng(seed, rowIndex): grass 1–2 rows, road runs 1–3 lanes.
  • Per lane: direction, speed 1–2, 1–3 cars, with Σ(length + speed) ≤ 5 so at least 4 cells are clear each beat.
  • Solvability check: car positions repeat every 9 beats, so a BFS over (row, col, beat mod 9) proves each road run can be crossed, or regenerates it.
  • Cars wrap around modulo 9. head is the front cell. Collision: the frog moves first; it's hit if its new cell is anywhere the car covers or sweeps through that beat.
  • Edge moves become wait. Distance = furthest row reached.
Beat loop · lib/game/loop.ts → prd: Core Journey
  • getMove → step → render → at least 350 ms per beat.
  • Run ends on hit, or stalled after 15 beats with no forward progress. Both go to the coach.
  • Keeps the last 6 beats for the lesson.
Fast decisions · lib/system1 + /api/move → prd: Fast decisions (System 1)
  • decide({state, moves, playbook}) → {move, probabilities, confidence, source}
  • jev.ts: plain fetch to the gateway. fake.ts: offline stand-in, panel shows SIMULATED. Chosen by SYSTEM1.
  • Invalid answers are errors; the route never guesses.
Coach lessons · lib/system2 + /api/lesson → prd: Coach lessons (System 2)
  • Token Factory chat completions, nvidia/Nemotron-3_5-Lightning, max_tokens: 400, thinking off via chat_template_kwargs.enable_thinking: false.
  • Replies with two lines: What happened: and Rule: (≤20 words, game vocabulary).
  • If the reply is empty or cut off, the lesson counts as failed and the next run starts unchanged.
Panel & canvas · components/ → prd: Screens and Layout, Look and Feel
  • Decision box "JEV · via Vercel AI Gateway": move, confidence bar, five probability bars.
  • Coach box "NEMOTRON · Nebius Token Factory": thinking…, what happened, the new rule.
  • Playbook (newest flashes), runs with distance, a timeout marker, the best run starred, and the seed.
  • Style-B palette, 16×16 outlined sprites, Press Start 2P headings.

BUILD STEP 1: THE LESSON TEST

Your question: how does a lesson change the frog's next move? Jev scores each move's description against the state and the instructions. A rule in the same words should shift the scores, but evidence from CLM, Jev's open lookalike, says written rules steer weakly. So we measure it before building the game.

First real run (Sep 25): "Jump forward" alone gives forward 0.71 in the fatal case. With the lesson in the instructions, wait 0.93, and the control stays forward 0.79. The lesson works, and the instructions slot beats the description slot (0.87).

Plus one real Nemotron lesson call to confirm thinking is off. If no placement flips the fatal case, we stop and decide together before building more.
