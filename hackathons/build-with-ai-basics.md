## Re-read 2026-10-21 (rules and main page, in Chrome)
- **License now required here too.** The repo "should be open source by including an open source license file", detectable in the About section. MIT is in and GitHub detects it.
- **Video:** under 3 minutes, footage of the project working, public on YouTube or Vimeo, and it "must not include third party trademarks, or copyrighted music". Keep the word Galaga out of the video and its title and description.
- **Stage one** is pass/fail on fitting the theme and being built with the skill pack, "as evidenced by the planning documents in the repository".
- **Judging criteria, as worded now:** Design asks for "a complete, coherent product experience"; Potential Impact asks for "a credible, specific case for solving a real problem for a real audience"; Presentation asks whether the video shows it working end to end and whether the pitch says what problem it solves, who it's for and why it matters.
- Judging "may utilize expert panels, peer review, automated AI-driven analysis".
- The rules don't ban AI-written text, but the submission must be "the result of the Entrant's ideas and creativity". The skill pack's own `6-ship` is stricter: the entrant writes the narration and the submission text, and the agent only fixes spelling and grammar.

## Eligibility
- 18+. Individuals or teams. Sanctioned regions excluded (Brazil, Quebec, Russia, Crimea, Cuba, Iran, North Korea, others).

## What to build
- A new project made during the window with the Devpost Learn Skill Pack (`npx skills add challengepost/learn-ai-basics --all -y`)
- "A small app that runs and does one thing end to end"
- "Old ideas are fine, old code is not." Frameworks, libraries, starter templates and AI coding assistants are allowed. Disclose any other pre-existing code.
- Repo must include `scope.md`, `prd.md`, `spec.md`

## Submission
- Public GitHub/GitLab/Bitbucket repo with all source and assets
- Demo video under 3 min (YouTube/Vimeo) showing it working end to end. "Reviewers won't clone or run code, so the video has to show it working."
- Text description: features, problem, audience
- English, or English translations

## Judging (equal weight)
Design, Potential Impact, Innovation/Idea, Presentation

## Prizes ($2,500)
1st $1,250, 2nd $750, 3rd $500, each with a newsletter feature, interview and social posts. Everyone gets a badge and Discord role.

## Rules that matter for a shared project
- Multiple submissions allowed if "unique and substantially different."
- Submitting the same project to another hackathon: not addressed.
- IP stays with you. Devpost can promote the project and use your name/image for 3 years.
- No edits after the deadline.
