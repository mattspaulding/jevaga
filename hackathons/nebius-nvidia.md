# Nebius x NVIDIA Global AI Hackathon

Pulled 2026-09-25 from https://nebiusglobalaihackathon.devpost.com/ (main, rules, resources). Re-check the rules page before submitting.

## Re-read 2026-10-21 (rules page, in Chrome)
- **Video must be on YouTube** (not Vimeo), under 3 minutes, and must not include third-party trademarks or copyrighted music. One YouTube video can serve both entries.
- **README must highlight** "how you've used NVIDIA Nemotron or other NVIDIA open source models and where Token Factory accelerated your workflow and any other Nebius Tools or Services used." The README says what Nemotron does but not this.
- "Runs on Token Factory" means "the project makes a runtime call to the Token Factory inference API". `lib/system2/coach.ts` does.
- License must be detectable in the repo's About section. GitHub detects MIT.
- Stage one: "a genuine attempt at the track's stated goal, not a superficial rebrand". Best Apps and Agents is the closest track: "any app or agent someone would actually use".
- Quality of the Idea now reads: "a creative, non-obvious use of Nebius Token Factory ... and NVIDIA Nemotron ... and does the team show genuine understanding of the problem space?"
- Most Valuable Feedback ($100 + swag, 10 of them) is judged on "completeness, viability, and potential impact of the feedback."

## Dates
- Submission window: 2026-08-26 to **2026-10-30, 10:00 AM PDT**
- Judging: Dec 1 to 15, 2026. Winners around Jan 11, 2027. The project must stay free to use and working until judging ends. (Rules page, verified 2026-09-25.)

## Eligibility
- Age of majority where you live. Individuals, teams, organizations.
- Excluded: Brazil, Quebec, Russia, Crimea, Cuba, Iran, North Korea.

## Required tech (pass/fail)
- Must run on **Nebius Token Factory or Nebius AI Cloud**
- Must use **at least one NVIDIA open-source model**. Nemotron (3 Ultra, Nano, Super) encouraged.
- Optional: NVIDIA NemoClaw, OpenShell, Hermes Agent. Tavily has its own bonus prize.

## Credits
- $25 code `NEBIUS-DEVPOST-GLOBAL26` (claim via form)
- Another $25 from the Nebius Builders Program, plus Tavily and Nebius Academy credits
- Builders & Brews in-person events (16 cities, Sep to Oct 2026) unlock more

## Tracks
1. Coding and Agentic Engineering: agents that write, run and test code
2. Best Apps and Agents: productivity, copilots, autonomous workflows
3. Personal AI: always-on private assistant, your data under your control
4. Physical AI: robotics/IoT/edge, needs 1+ min of real hardware footage

## Submission
- Public repo (GitHub/GitLab/Bitbucket) under Apache 2.0, MIT or MPL 2.0
- README with setup and usage
- Working demo URL (hosted app or test build)
- Demo video, max 3 min, with audio, public on YouTube, showing how you used Token Factory and Nemotron
- Project description
- Feedback on Nebius Token Factory, AI Cloud, NVIDIA tools
- Written explanation of what changed if the project existed before 2026-08-26
- Builders & Brews city, if attended

## Judging
- Stage 1: pass/fail viability
- Stage 2, 25% each: Technological Implementation, Design (complete product vs. proof of concept), Potential Impact, Quality of the Idea

## Prizes ($50k+)
- Grand $20k, 2nd $10k, 3rd $6k
- Track winners: NVIDIA Jetson Orin Nano (one per track)
- Best Use of Tavily: $3k
- City winners: $500 x 20
- Most Valuable Feedback: $100 + swag x 10
- "Each Project is eligible for one (1) Overall Award OR one (1) Track Award and one (1) Bonus Award."

## Rules that matter for a shared project
- Multiple submissions allowed but each must be "unique and substantially different."
- Submitting the same project to another hackathon: not addressed.
- Pre-existing projects must be "significantly updated" in the window, with a written explanation.
- IP stays with you; sponsors get a non-exclusive license for judging and promotion.
